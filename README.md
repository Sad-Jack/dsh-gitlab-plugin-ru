# GitLab — русская редакция для DeepSeek Harness

Интеграция GitLab с рабочим пространством и инструментами Harness.

Независимая локализация [dsh-gitlab-plugin](https://github.com/k0ndrateff/dsh-plugins/tree/main/packages/gitlab). Версия пакета — `0.4.1-ru.3`, исходная версия — `0.4.1`.
Русскую редакцию подготовил [Sad-Jack](https://github.com/Sad-Jack) с помощью Codex и Codex-агентов.
Оригинальные авторы и лицензии указаны в [UPSTREAM.md](UPSTREAM.md).

## Возможности

- Подключение к вашему экземпляру GitLab.
- Русские описания инструментов и настройки.
- Сохранённые идентификаторы и схемы параметров исходного пакета.

## Установка

Проверено с DeepSeek Harness **0.2.1-rc.5**. Требуется доступная команда `dsh`.
В репозитории лежит готовый пакет с JavaScript-модулями. Отдельная сборка TypeScript для установки этой редакции не требуется.

```sh
git clone https://github.com/Sad-Jack/dsh-gitlab-plugin-ru.git
cd dsh-gitlab-plugin-ru
dsh plugin --profile desktop add "$PWD"
```

После установки перезапустите Harness. Для другого профиля замените `desktop` в команде.
Идентификатор пакета — `dsh-gitlab-plugin`. Если исходная версия уже установлена, русская редакция занимает её место в выбранном профиле.
Ключи доступа и адреса своих сервисов задавайте в настройках Harness.

## Что переведено

Интерфейсные строки, описания инструментов, инструкции ролей и навыков, а также поставляемые README и справочные документы.
Команды, JSON-поля, имена функций, идентификаторы, URL и технические примеры сохранены там, где их изменение влияет на работу.
У исходных цитат и примеров могут оставаться оригиналы рядом с русскими пояснениями.

## Проверка и совместимость

Проверены загрузка модулей в среде Harness, метаданные, структура инструментов, ссылки и технические блоки документации.
Для библиотек навыков дополнительно сверены идентификаторы и состав каталогов.
Полная работа каждого инструмента с внешним сервисом или целью отдельно не проверялась.
После установки на вашем компьютере потребуется проверить интерфейс и настроить необходимые подключения.

Обновления оригинального пакета не объединяются автоматически. При обновлении потребуется повторно проверить локализацию.
Детали редакции — в [LOCALIZATION.md](LOCALIZATION.md).
